AchillesCLI Agent Suite

This repository combines AchillesCLI with four optional Ploinky workers. AchillesCLI is the user-facing local and WebChat agent; GPTResearcher performs research, while Codex, PI, and OpenCode execute delegated coding tasks.

How the agents work together

AchillesCLI handles the active user conversation and owns the stable local task record. When a user explicitly requests another agent, AchillesCLI asks Ploinky to start the corresponding manual worker, submits the work through the router, and returns control to the conversation while that worker runs. The worker owns its provider-specific session, logs, credentials, and continuation details.

Choose an agent

Use AchillesCLI for interactive project work, local skill execution, session management, and coordination. Ask GPTResearcher for a sourced report that may combine the web with workspace documents. Ask Codex, PI, or OpenCode when you want a coding provider to work asynchronously and preserve its own task context for follow-up prompts. The three coding workers implement the same general Ploinky task contract but retain their provider's native execution and session behavior.

Shared operational boundary

The four workers are optional and use manual startup. They do not join the AchillesCLI startup graph until a request needs them. Ploinky supplies agent activation, router authorization, persistent agent homes, and task transport. AchillesCLI remains responsible for the user-visible session and local task identifier, while each worker keeps provider-specific continuation state private.
