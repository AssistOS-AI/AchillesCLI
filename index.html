How the agents work together

RoboTeam handles each robot conversation and its delegated task records. Skills submit optional worker or robot tasks through the Ploinky Router and observe logs and completion without replacing the parent conversation.

Choose an agent

Open the default robot for interactive project work. Other robots expose the same conversational commands with their own accounts and selected skills. GPTResearcher retains its research task contract.

Shared operational boundary

Explorer enables RoboTeam globally. Optional workers start only when requested. Ploinky owns routing and authorization, RoboTeam owns robot sessions and GUI lifecycle, and ALA runs the selected native coding agent inside Bubblewrap.
