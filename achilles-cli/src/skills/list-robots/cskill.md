# List Robots

## Description
List the RoboTeam robots owned by the current authenticated user. Use when the user asks which robots are available before selecting one for work.

## Input Format
No arguments are required. Any supplied text is ignored.

## Output Format
Plain text containing each robot name, specialization, and current run state.

## Constraints
Use only the router-mediated internal RoboTeam MCP tool and return the workspace robot catalog.
