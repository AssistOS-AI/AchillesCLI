GPTResearcher Agent Documentation

Research terminology and service boundaries.

GPTResearcher

The optional Ploinky research worker owned by AchillesCLI. Authorized callers submit a question through start_research, and the pipeline writes a timestamped Markdown report in the resolved working directory. It returns report text, path and available evidence metadata. The worker starts on demand; a failed model or search adapter prevents a successful report result.

Research report

The Markdown output written after the upstream pipeline conducts research and produces the requested report type. The filename combines a UTC timestamp with a bounded query-derived slug. The returned structured result identifies the path and includes available sources, context, costs and a bounded log tail. Report storage is confined to the resolved working directory.

Hybrid research

The upstream research mode selected when useLocalDocs is not false and the working directory contains eligible files. GPTResearcher supplies the folder as DOC_PATH and combines local material with web research. Explicitly disabling local files, or finding none, selects web-only research. Local filenames are not appended to the web query.

Research working directory

The request's workingDir resolved against WORKSPACE_PATH using real paths. It defaults to the workspace root and is created when needed. Paths outside that root, including symlink escapes at resolution, are rejected. Eligible top-level files provide optional local research evidence, and the completed report is saved in the same directory.

Soul Gateway

The model service selected by GPTResearcher's language and embedding adapters. Persistent settings select fast, smart, strategic and embedding models without storing provider secrets. Generated-local routing signals cause PLOINKY_LOCAL_GENERATED_CONSUMER_NOT_CERTIFIED before the Python adapter reads routing credentials. That transport boundary must be certified before managed Box research can use it.

SearchAgent

The routed search service used by the GPT Researcher retriever adapter. Queries are submitted through Ploinky's AgentMcpClient to searchAgent.search_agent_search; the worker does not call external search vendors itself. A non-secret setting selects the search provider, while keys remain owned by the search service. Missing or unauthorized transport is an operation failure.
